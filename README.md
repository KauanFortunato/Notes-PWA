# Notas PWA - Projeto de Aplicação Web Progressiva
## Requisitos
.NET: https://dotnet.microsoft.com/en-us/download

GIT: https://git-scm.com/downloads

Visual Studio(Opcional): https://visualstudio.microsoft.com/downloads/

---
## Passo a Passo para Instalação e Execução
### Usando Visual Studio
1. Clone o repositório:
	- Quando você estiver na janela de ínicio do Visual Studio, clique em `clonar` repositório e use o link:
	
		```
		https://github.com/KauanFortunato/Notes-PWA
		```

2. Rodar a aplicação:
	- Pressione F5 ou clique em iniciar para rodar a aplicação.
	- O navegador padrão deve abrir e carregar a aplicação web progressiva (PWA).

### Usando Terminal para Clonar o Repositório
1. Clone o repositório:
	- Abra o terminal e navegue até a pasta onde você quer clonar o repositório.
	- Use o comando para clonar:

		```
		git clone https://github.com/KauanFortunato/Notes-PWA
		```

2. Rodar a aplicação:
   - Use o comando dentro da pasta `Notes-PWA`:
		dotnet run
	- Você deve ver um endereço como esse `http://localhost:5281`, copie e cole em seu navegador.
